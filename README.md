# Openms Openms

## How do I install these formulae?

`brew install openms/openms/<formula>`

Or `brew tap openms/openms` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "openms/openms"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
